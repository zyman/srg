# Security

SRG is an experimental infrastructure-control reference implementation. It has
not received an independent security audit. Review its threat boundaries and
limitations in FRAMEWORK.md before granting access to real resources.

Report suspected vulnerabilities through this repository's **Security → Report
a vulnerability** form. Do not put credentials, private host details, complete
audit exports or exploit details into a public issue. If a credential may have
been exposed, revoke it at its source rather than only deleting its gateway copy.

This community project provides no guaranteed response time or support SLA.
Security fixes will be documented in the repository. Keep destructive and
security-sensitive operations outside routine agent grants.
